# 设置说明

> [English](SETTINGS.en.md)

每一项功能做什么见[功能一览](FEATURES.md)。

设置页同时出现在设置对话框（「Claude Style」标签页）与插件页，分为六个分页：

| 分页 | 设置项 |
|---|---|
| 通用 | 主题风格、用户名、页面缩放、悬停展开弹层 |
| 外观 | 配色、字体、首页版面（及其下的水波纹字符背景）、吉祥物、出现位置、品牌名称、标志图片、文字标志、图片颜色、主色 |
| 输入区 | 输入区重绘范围、重绘模型选择器（及其下的模型描述、快捷供应商与峰谷电表）、重绘权限控件 |
| 侧栏 | 折叠侧栏设置区（及其下的封号彩蛋：关闭 / 中文 / English）、侧栏搜索、搜索框样式、进行中 / 已归档视图、面板悬浮卡片、左侧栏布局（宽松 / 紧凑） |
| 对话 | 对话导航、对话统计信息位置（收进上下文 / 独立成行）、对话 / 轨迹标签条、会话标题进入顶栏 |
| 动效 | 动画效果、聊天区滚动动画（跟随末尾 / 行与过程组的开合 / 文件操作行）、状态行动画（一个开关，下面依次是「精确状态行」开关与两张卡：扫光 / 渐变流动）、光标动画（开 / 关）、新文字淡入（淡入 / 直接出现）、消息气泡动画（一个开关，下面两张卡：在原地长出来 / 从输入框飞上来） |

每一项接管宿主界面的功能都有自己的开关，关闭后宿主原来的界面原样回来，不需要刷新页面。「聊天区滚动动画」管的是对话区里随内容滚动的那三样——跟随末尾、行与过程组的开合、文件操作行——开启时播放本插件的这一套，关闭后这三样交回宿主，宿主自己的做法也一并回来；「动效」页里的状态行动画与消息气泡动画各自带一个开关，不再跟它一起走，光标动画与新文字淡入也照旧各自有开与关两档。

「动画」设为「减弱」时，「动效」页里状态行画法、光标动画、新文字淡入与消息气泡动画的卡片略变暗并各停在一帧（扫光的高光带停在字中、光标带滑行拖尾、淡入的末几个字停在渐淡的各档、气泡停在长大或升起的途中），行下方写明这一项此时不生效，选择仍可修改。

有几项只在另一项打开时起作用，那一项关闭时它们变灰、不能操作，仍显示你设的值，说明下面写明在等哪一项：「重绘模型选择器」（连同模型描述、快捷供应商与峰谷电表）和「重绘权限控件」画在重绘后的输入区里，输入区重绘范围选「关闭」时变灰；「对话统计信息位置」只在输入区重绘覆盖对话页（「仅对话」或「全部」）时起作用；「封号彩蛋」从账号弹层打开，「折叠侧栏设置区」关闭时一起变灰。「会话标题进入顶栏」只作用于 Windows 桌面端的窗口，在别的页面（浏览器、macOS 窗口）里同样变灰，仍显示你设的值。

**页面缩放**：这一行的标题旁带「实验性」标记。把整个页面按倍数绘制——界面、文字、控件与图片一起变大或变小。「随系统」跟随系统与 DSH 给出的尺寸，其余四档分别是 0.8x、1x、1.25x、1.5x。窗口尺寸不变，页面按缩放之后剩下的空间重新排布，所以放大档位下侧栏与对话区会窄一些、0.8x 下会宽一些；贴着输入区展开的模型、努力度与权限弹层仍与各自的按钮对齐，设置页本身也按同一倍数绘制，档位可以在这一页上直接比出来。桌面端窗口自己的三个按钮与它们所在的那一行在页面之外，尺寸不变。

**水波纹字符背景**：「外观」页首页版面下这一项默认关闭，标题旁带「实验性」标记。打开后新会话页的背景换成一片等宽字体的数字与字母，每秒重绘两次，被缓缓漂移的云层遮住；点击页面荡开水波，波速在点击处最快、越远越慢，被波扫过的字符显现出来，波前染蓝、尾迹留灰并淡去。

**封号彩蛋**：点账号弹层顶上的账号行，打开一张仿 Claude「账号已暂停」的整页彩蛋，按「侧栏」页这一行选的语言显示，与界面语言无关。选「关闭」后账号行只显示名字，按它不再打开任何东西。

设置对话框里这一页的标题行右端有一枚 GitHub 标识，按一下在新的标签页里打开插件仓库。

**从远程地址打开**：宿主把它信任的地址上打开的每一个页面看作同一个使用者的页面，经局域网地址或隧道打开的页面（手机、另一台电脑）与运行 DSH 的电脑上那一页读写同一份设置，任意一边改动，另一边不需要刷新就会跟上。宿主不信任的地址上，页面连不上宿主。

**自定义品牌**：「外观」页末尾几行把你自己的品牌放到「主题风格」所选的品牌之上。「品牌名称」替换侧栏顶部的品牌文字；「标志图片」替换侧栏顶部、折叠栏、新会话页与账号行兜底头像上的标志；「文字标志」替换标志旁的名称，宽度按图片比例随高度换算，有它时不再显示品牌名称。图片收 PNG、SVG 与 WebP，单张不超过 2 MB，存在 DSH 主目录的 `dsh-claude-style/brand/` 下，也可以直接把 `mark.png`（或 `.svg`、`.webp`）与 `wordmark.png` 放进这个目录，刷新页面后生效。「图片颜色」选「原色」时图按自己的颜色显示；选「文字色」时图被当作形状，按所在位置的文字颜色上色，适合单色标志，亮色暗色下都看得清。「主色」改按钮、选中标记、链接与焦点环的颜色，按钮上的文字自动取深色或浅色；未指定时沿用所选品牌的主色，「配色」选「跟随宿主」时主色不生效。每一项留空或移除后，对应位置回到所选品牌的原样。

**模型描述**：重绘后的模型菜单一级列表里，每个模型名下面写一行说明，讲这个模型是什么。说明按名字模式从随包附带的文案表里取，表里没有对上的模型只写名字；「更多模型」那一层不写说明，那里是各家供应商的完整目录，只留模型名更好认。关闭后每一行只剩模型名，选择器其余部分照旧。

**峰谷电表**：模型菜单的每一行标出该模型此刻的倍率。峰价、谷价与限时活动三种状态各有自己的图标，颜色区分贵与便宜，倍数后面跟着距离切换还有多久；鼠标停在徽章上，悬停提示写出此刻的完整判定与切换后的状态。判定按各家供应商自己发布的作息表与自己的时区做，工作日窗口之外、周末与法定节假日整日都算谷价，跨零点的窗口归它开始的那一天。没有任何作息表的模型不显示徽章。作息表是公开目录 [offpeakclock.com](https://offpeakclock.com) 里的一份快照，由宿主半边（而不是页面）取一次、在本机留一份缓存并按 24 小时刷新；连不上时按插件包里带的那份判定。

**侧栏搜索**：开启后侧栏里多一个搜索框，打开的面板能找会话（标题与内容）、项目、插件、Skill 与快捷键；点开一条内容命中，页面落到那条消息所在的一轮，历史很长时先把这一轮的记录翻页读进来。「搜索框样式」决定它站在哪里：「覆盖品牌」（默认）把它放进品牌行，指针移到侧栏上时它盖过品牌，指针移开再把品牌让回来；「独立」在品牌行下方给它自己一行，一直显示；「图标」不画插件自己的搜索框，让 DSH 自己的搜索按钮留在原处，只把单击接管过来，点它打开的是本插件的面板。内容匹配只认你发出的消息与模型的回答，注入的环境提示、Skill 目录与推理过程都不进结果。

**左侧栏布局**：「宽松」（默认）是现在的样子；「紧凑」只把间距收小——上侧各行（新会话、插件、自动化任务，以及搜索框独立成行时的那一行）到工作区之间的空隙、工作区标题自身的上下留白、对话行的高度与行间距、两个分区之间的间隔，以及账号区内边距与它那一行的上下边距。控件的形状、字号、图标与配色都不动，因此两种布局下点得到的东西一样多。

**与其他主题插件同时使用**：「配色」与「字体」选「跟随宿主」后，本插件不再改写宿主的颜色与字体，只保留布局和控件；颜色交给 DSH 自己，或者交给同时启用的其他主题插件。例如与 [dsh-wallpaper-engine](https://github.com/elysia395/dsh-wallpaper-engine) 一起用时，壁纸透过侧栏与对话区显示出来，插件自己的弹层随壁纸插件的玻璃效果变成半透明并模糊背后的画面。**与 [dsh-chat-ux](https://github.com/alm-allen/dsh-chat-ux) 同时使用时**：那个插件实现了同一批聊天区交互（卷帘门、自动开合、文字淡入、文件变更行、聊天气泡动效、插入符动效），两套同时生效会互相拦点击、抢同一批按钮。所以本插件在检测到它时让位：设置页「对话」页的「聊天区动画效果」与「动效」页的「光标动画」「新文字淡入」三行控件禁用，但仍显示你自己设的值，下面另起一行用强调色注明「该选项由 dsh-chat-ux 管理」；你的设置不会被改写，卸载 dsh-chat-ux 之后原样生效。**与皮肤中心里的皮肤同时使用时**：皮肤中心把本插件列为可选皮肤，选中它即把整页交给本插件；换选别的皮肤时本主题整页让出，侧栏、对话、输入区与设置页一并撤下，页面由那款皮肤与宿主自己画，在皮肤中心里本插件那一行选回本主题即恢复。

**聊天区跟随**：思考行收起、工具调用行出现这些结构时刻，贴着底部的读者被交还给系统自己的跟随，内容成片到达时不再停在离底部几十像素的地方；「标准」与「简洁」档里封顶的过程组（思考与工具输出收在一个带滚动条的组体里）同样补到底部。补到底部走的是曲线：零散到达的字收得住尾巴，成片涌进的文字以一段稳速滑过去，再落到末尾。流式输出期间位置由宿主自己的跟随写到末尾，新长出的内容从屏幕下缘平滑滑上来，上方文字不再一帧跳上去，状态行停在原处不动；这段滑动由显卡完成，不占用页面的布局，多个会话同时输出时也不加重负担。你自己发出的消息不走这条曲线：宿主把它滚进视野的那一下照旧一步到位。读者自己滚动离开底部之后，插件不再插手，直到他自己回到底部。

**思考与过程自动开合**：模型还在思考时思考行开着，思考停下就收回去；运行中的过程组自动展开，这一段结束再收起。读者自己按过的行或组在当时的阶段里不再被改动。

**推理回放窗口**：开着的那段思考停在一个跟着它长高的窗口里：窗口先是和文本一样高，长到推理能到的最大高度（宿主给过程组正文的那个上限）就停在那里，文字从这一刻起每 0.84 秒往上走两行（0.5 秒滑过去），到最新一行就停住，上下边缘渐隐；窗口没长满之前文字不渐隐也不滑动，读者照着平时的样子往下读，整列对话也只在长到上限这一段被推开。推理一停，窗口撤下，读者打开这一行读到的是完整文本；「动画」设为「减弱」时不设这个窗口，思考行照宿主的样子完整铺开。

**过程组标题上的计数**：过程组的标题不再只写「执行了命令，已读取文件，已调用工具等」，而是写这一组装了什么，例如「执行 2 次思考，调用 1 次工具」；没有的项不写，数字随内容增加逐位滚动，这一段还在进行时整行带着与宿主同样的扫光。这一行放不下整句时（窗口窄、过程组所在的行窄）改用简洁写法「思考×2 · 工具×1」，位置宽回来再换回整句；控件的可访问名字始终是整句。

**模型正在做什么的那一行**：轮次进行中，对话末尾那一行不再是固定的「深度求索中，用时 N 秒 ···」，而是写出这一轮此刻在做的事：「正在思考」「正在准备工具调用」「正在调用工具」「正在写回答」，后面跟着这一轮已用的时间（用宿主自己的单位）。两种状态说的是具体的东西：调用在跑时写出它操作的文件（「正在读取 app.js」「正在编辑 notes.md」「正在写入 out.txt」，只取文件名），推理正文里出现进行时从句时把模型自己那句话写出来（「Checking the file is true」：从动词截到这一句的句末；句子在哪里断开交给页面自己的句子规则，所以文件名与版本号里的点号不算句末；否定的句子、还没动手的打算、引号里的话与读不出从句的正文都不取——模型引用它读到的一句话、甚至引用这一行自己那个等待词时，那不是它在说自己正在做什么；取不到就回到「正在思考」）。这两种说法都整句带出来，不按字数截断：放得下多少由这一行自己的宽度决定，放不下时在断开处画省略号，计时与徽标留在原处。这一行跟着宿主自己的发布走，调用刚开始跑就被读到；每种说法写上之后锁住 1 秒，这一秒里状态再换也不动，锁一过就直接写当时最新的状态（中间来过的那些不补演），因此一个轮次里状态换得再快，这一行也只一秒换一次；被锁跨过去的调用说法不在此列——一次读完的小文件调用会在锁一过先补上它，再轮到当时的状态。模型自己那句从句另有一条：两次从句之间读不出东西的那几拍（正在思考，或刚起一步还没写下什么）不把它换掉，它一直站到下一次意图到达为止——新的从句、调用自带的说法，或写回答这类状态；「精确状态行」关掉时本来就不读从句，也就无所谓站住。说法换掉时旧的向上淡出、新的从下方升起，两段重叠着一同走完（整次约 0.2 秒，来自 transitions.dev 的「Text states swap」）；说法盒子换宽度时，旁边的计时随之滑到新位置（约 0.24 秒），不做两次跳变；一直读不出状态时这一行说这个品牌自己的那一个词，与模型思考时说的同一个：Claude 品牌下「正在思考」，DeepSeek 品牌下宿主自己的「深度求索中」；模型连续 10 秒没有开口时，计时后面多一枚「暂未响应」。这一行带扫光；宿主的小鲸鱼是 DeepSeek 自己的形象，Claude 品牌下它让位给本插件自己的加载点：三枚 4px 圆点用当时生效的主题色，模型思考时它们照旧弹跳（各自弹起 8 像素并在离地时压扁，半秒一次，第二枚与第三枚分别错开五分之二与五分之三个周期），这一轮改成写回答或调用工具时换另一套走法——三颗点各沿一条直线来回，三条直线彼此相差 120°、其中一条反着走，球在两端最大、过中点最小，一个来回 1.25 秒、去程与回程一样长；两套走法之间不硬切：旧的那一列各自淡出、新的那一列各自淡入，每颗球都在自己动作里的那一拍上开始——跳球从落地回弹那一刻开始淡出、到最高点淡完，从最高点开始淡入、到落地淡完；走路从线的一端开始淡出、到中点淡完，从中点开始淡入、到另一端淡完，没有哪颗球被挪到别的动作的位置上；一个动作站满 2 秒才允许下一套接手，这段时间里来了又走的状态不打扰它；其余品牌下宿主的鲸鱼尾照旧，读屏播报也照旧；说法比这一行放得下的宽度更长时，它在这个宽度上截断并画省略号，计时与徽标留在原处；「动画」设为「减弱」时说法直接换掉，不做上面那两段。只要对话还在跟随末尾，这一行就停在输入框上方，不断追加的内容不再带着它上下移动；读者自己往回翻看时它照常随内容走。

**聊天气泡动效**：提交消息时输入卡片原样浮起、一路收成那条气泡，草稿里的字跟着形状重新排，落地正好接上真实的消息行：真实气泡在下面先显示出来，飞行的那份淡出，文字逐渐变清晰。

**文件变更行**：run_code 程序里派发出去的写入与编辑带上行尾的 `+n -m` 与可展开的改动卡片，路径可点开文件；失败与中断的行保留裁决信息。

**新文字淡入**：「动效」页的这一项管流式回答里新出现的字符。开着时它们先淡后实（约 0.12 秒），并按到达次序略作错开；整段一次到达的内容、几千字的突发与刚被折叠重排过的文字保持本色。两档都不带文字，各带一张预览卡，同一句样品在两张卡里逐字到达：「淡入」那张每个字落到最淡的一档再亮起来，「直接出现」那张把字一个个直接交出来，走完停一会儿再来一遍。这一项默认关闭；「动画」设为「减弱」时对话区不再淡入，两张卡各停在一帧：淡入那张末几个字停在渐淡的各档，直接出现那张是整句，卡片略变暗，行下方写明此时不生效。

**消息气泡动画**：「动效」页的这一项管自己发出去的消息落到对话里时怎么出现，自己带一个开关，关闭时这一项交回宿主（下面那两张卡片同时变灰、不能操作）；两档都不带文字，各带一张预览卡，卡里是一小段只有用户气泡的对话，下面那一条在两种说法之间轮流换（一条落定、另一条接着来，走完再从头）。「在原地长出来」让气泡在自己的位置上从零长到满（约 0.32 秒，末尾轻微过冲，放大起点是气泡自己的右下角），行高与旁边的东西全程不动；「从输入框飞上来」是原来那一下：输入框那张卡片被抬起来飞到消息那一行，真消息在飞行期间藏着，落到那一行时交接。「动画」设为「减弱」时两条消息都不动，气泡直接站在它该在的位置。这一项默认「从输入框飞上来」。

**卷帘门过渡**：点开或收起一行（工具卡片、思考行、命令卡片）以及过程组时，高度逐帧变化，下方内容被真的推开或收回；门只走读者看得见的那一段，内容再长也是同一速度，多张卡片的展开体整扇门一起走。它与展开体的入场淡入一起由「聊天区滚动动画」开关。

**输入框插入符动效**：输入框里的光标由插件自己绘制，移动时滑过去；提问卡片的作答框与排队消息的行内编辑框同样覆盖。设置页的「动效」页有开与关两档，各带一张预览卡，都不带文字：卡里逐字打出 `Hello World!`，光标跟着这行字往前走，打字期间一直亮着，打完停住才按原生节奏闪（真光标每移动一次就把闪的节奏从头开始，所以打字时看不到它灭）。两档的分别在于光标怎么到达下一个位置：「开」的那张滑过去，「关」的那张与宿主自己的光标一样直接跳过去。

**状态行动画**：「动效」页的这一项，管的是轮次进行中、对话末尾那一行文字上的动静，自己带一个开关，关闭时这一行交回宿主（它下面那两行——「精确状态行」与两张画法卡片——同时变灰、不能操作）；开启后，紧跟着的「精确状态行」决定这一行说得多细：开着时写具体在做什么（正在操作的文件、命令声明的描述、推理里的原句，所以中文与英文会混着出现），关掉只写状态本身。再下面那两张画法卡片都不带文字，卡片里就是这一行自己的样子，一直在动：里面的字在两种说法之间来回换——旧的向上淡出、新的从下方升起，就是状态行换词的那套动作（「精确状态行」开着时改在三条样例之间一次一条地换：正在阅读README.md、Checking out current tree、正在思考）——画法则是默认的「扫光」：一道高光带贴着字形扫过，与宿主自己的行同一节奏；另一档「渐变流动」让文字本身流动着变色，七层径向色斑压在一条灰色渐变上，色斑绕着字框游走，同时整圈色相在转。点一张卡片立刻换过来；真实状态行的说法、换词与旁边的时间两档都一样；「动画」设为「减弱」时画法停住（扫光与渐变都不再走），说法照旧一轮一轮换，只是换成瞬间切换——不再演离开与升起那两半，预览卡与状态行在这一点上一致。

**对话统计信息位置**：会话的八个数字有两个去处。「收进上下文」（默认）把它们放进那枚上下文计量饼的弹层，输入卡片下方只留那枚饼；「独立成行」把其中的轮数与步数、输出速度、读入的 tokens、写回的 tokens 与缓存命中率写在输入卡片下面单独一行，末尾就是那枚计量饼。这一行里的数字接到新读数就从眼前的数连续计数到新值（每走一个步骤、流式输出期间都在动），中途再接到新读数就从当时的值接着走，切换会话时也从上一段的数字计数到新一段的；缓存命中那一截的色带只染数字与百分号，前面的字样留在这一行自己的颜色，命中率从九成的红走到 99% 的深绿，计量饼按占用自己在四成的绿到八成的红之间取色。窗口窄到这一行放不下时它会依次让位：先去缓存那截的字样，再去轮数与步数，再去计量饼旁的数字（饼留下），然后把读入与写回合成一个合计，最后把数字折叠成 k / M / B；窗口宽回来时按同一顺序退回。

**对话导航**：对话区右侧那列短横线每一轮一条，跟着你读到的位置走。鼠标碰到它，它就展开成一张列表：每一行写着开启这一轮的那条消息，正好落在它那条短横线原来的位置上——你正在读的那一轮还在原处，鼠标下面还是刚才那一轮；滚轮上下翻，点一行页面滑到那一轮，还没加载的早期对话先加载再跳；指针停在列表上时，对话区顶部的对话 / 轨迹标签照常显示。Alt+↑ / Alt+↓ 跳到上一轮或下一轮，连按会一轮一轮接着走；输入框里有草稿时这两个键留给输入框。跳到的那一轮开头会闪一条短横线。同时装着 [dsh-plugin-msg-nav](https://github.com/SherUnlocked-4869/dsh-plugin-msg-nav) 时，Alt+↑ / Alt+↓ 留给它。

**吉祥物**：输入框上沿站着一只像素小伙伴，随智能体的工作状态换动画（思考、写回答与调用工具、多个会话同时工作、子代理、等你操作、压缩上下文、完成、失败、睡着）。「跟随品牌」在 Claude 品牌下是像素螃蟹，在 DeepSeek 品牌下是小鲸鱼 Deepy，也可以固定选一个或者关闭；「出现位置」决定它只在新会话页出现，还是新会话页和对话页都出现。
