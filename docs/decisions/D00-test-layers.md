## 决定

- 所有测试由 `scripts/verify.mjs`（`npm run verify`）发起：同一工作树同时只有一次运行，锁在 `.debug/verify.lock/`；结论按树内容的散列与本次闸门集合记进 `.debug/verify-cache/`，同一棵树上的再次请求直接读结论并注明出处，`--force` 才重跑，等锁的请求在锁放开后先查一次结论。
- 不带参数的请求是迭代档：不需要构建的检查、构建，以及 `git status` 读出的 `packages/client/src` 与 `packages/contracts/src` 改动经 `vitest related` 到达的单元测试；这两处没有改动时跑整条单元通道。迭代档不起浏览器。
- 闸门按读什么分批：检查、构建与单元测试同批起跑，冒烟与端到端通道在构建写完 `lib/` 之后同批起跑；一批的耗时是其中最慢的闸门。
- 各档由参数点名：`--quick` 是冒烟快档加上改动所在功能目录的清单点名的行为场景，`--case` 与 `--feature` 走点名的冒烟用例并连带动效用例，`--full` 走整份冒烟，`--e2e` 与 `--scenario` 加上端到端通道，`--no-e2e` 去掉通道；除迭代档外都跑整条单元通道。`--full --e2e` 是发布闸门，先打印「请确认你正处于发布流程。」。
- 并发：冒烟页面按 `--jobs` 一起驱动；端到端场景按 home 的种类共用宿主实例、每个场景开自己的会话，声明了 `plugins`、`hostArgs` 或专用 home 的场景独占实例，`--shard` 取默认表的一份切片。
- 结论只对它读过的树成立：运行期间的改动让结论过期，`npm run dev` 换掉产物的那次运行不写结论。本机只在推送之前发起一次覆盖这次改动的最小集合，在后台运行；云端的构成与触发见 D69。
- 单元层（Vitest 浏览器模式）覆盖纯函数、状态机、偏好解析、总线与帧管线的顺序（D40）以及动效曲线在给定时间步序列下的输出；构建生成的模块按同一份数据写到 `.debug/vitest/`。
- 契约层是端到端通道的 `contract` 场景，在固定版本的真实宿主上逐条核对契约模块（D44），只回答宿主的假设是否还成立。
- 行为层跑在真实宿主与脚本化模型上，断言用户可观察的结果：属性、文字、元素在不在、滚动终点，以及页面自己记录的序列满足的不变式；钟点阈值、帧数与单个像素量值不进断言。
- 动效的断言读页面在帧回调里记下的值：序列单调、中间至少经过两个不同的值、终点等于目标；曲线的形状留在单元层。
- 静置的判定是 `document.getAnimations()` 全部结束且测试页的 MutationObserver 连续两帧没有记录；动画中间的状态把全部动画暂停，`currentTime` 依次设到开始、一半与末尾，各读一次。
- 外观层是计算值快照：走查在每个页面状态下按部件记录一份固定属性清单的计算值，快照进版本管理；快照运行只用随包分发的 OFL 字体，判定只在云端那个平台上作数。
- 冒烟层读构建产物与最小加载器，只回答：产物能装载、每个功能的安装与卸载成对、开关能翻转、卸载后 `<body>` 不留属性、延后的块能取到、控制台没有报错；宿主交互不在冒烟层判定。
- 长会话场景在两个会话长度上各测量一个回合：插件发出的整份文档查找次数与每批变更的脚本耗时，两个长度之比不超出边界。
- 检查表达式里的每个数字字面量记在 `packages/testing/check-numbers.json`，由 `npm run checks:numbers` 生成、闸门核对；改动一个检查接受的数值，这份记录跟着变，放宽因此出现在 diff 里。
- 边界值本身住在 `packages/testing/bounds.json`，每条带 `reason`；检查读它，不把数字写进表达式。快照改变而同一次推送没有改动 `packages/client/src` 时，`scripts/ci-scope.mjs` 判定失败。
- 行为层的失败默认是产品缺陷；放宽断言的提交在说明里写出旧断言误判了哪一种产品行为。
- 验证工具都在 `packages/testing/`：找浏览器、开上下文与页面、关浏览器只有 `browser.cjs` 一处实现。

## 理由

- 替代宿主只复现作者已知的结构，断言在复制品上成立，不证明在宿主上成立；宿主交互只有在真实宿主上测出的结果才作数。
- 钟点与帧数断言读到的是机器负载：同一份代码在忙的机器上失败，失败之后只剩放宽断言这一种处理；不变式与定格时刻让同一棵树每次得出同一个答案。
- 边界与快照集中在一处，放宽断言就成为看得见、要写理由的改动。

## 代价

- 行为层要本机装有 `dsh`；没有的机器只跑单元层与冒烟层，推送交给有宿主的机器。
- 宿主交互的回归要到 `--quick` 及以上的档才读到；共用实例的场景不能改动共享的 home。
- 外观快照绑定字体与渲染平台，本机生成的快照只供参考。

## 重审条件

- 宿主提供官方的插件测试环境时改用宿主的。
