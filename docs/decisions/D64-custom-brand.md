# D64. 自定义品牌是叠在两档品牌之上的一层

- **状态**：已实施
- **分组**：功能
- **关联**：D11、D12、D30、D38、D50、D60

## 决定

- 品牌仍是 Claude 与 DeepSeek 两档（D50），决定底色、基础标志与吉祥物；自定义品牌是叠在所选品牌之上的一层：品牌名称、标志图、文字标志、图片着色方式与强调色，每一项只在读者提供时生效，没提供的项保持所选品牌原样。
- 名称、着色方式与强调色是偏好（`brandName`、`brandInk`、`brandAccent`），经设置表单存进宿主的设置文档（D60）；两张图不进设置文档，存在 `$DSH_HOME/dsh-claude-style/brand/` 下，文件名为 `mark.<扩展名>` 与 `wordmark.<扩展名>`，只收 PNG、SVG、WebP，单张不超过 2 MiB。
- 宿主半边为图提供三条私有路由：`/dsh-claude-style/brand` 回答两张图在不在以及随字节变化的版本；`/brand/mark` 与 `/brand/wordmark` 以 `GET` 送出、`PUT` 替换、`DELETE` 删除。读写都过同一道围栏（D11）；写入先经临时文件再改名；图的应答带 `sandbox` 安全策略与 `nosniff`，单独打开一张 SVG 也执行不了脚本。读者手工放进目录的图在下一次读状态时生效。
- 浏览器半边由 `features/brand` 读状态与偏好，把每一项写成 `<body>` 上的属性（有标志图、文字标志是图还是文字、按文字色着色、有强调色）与对应的自定义属性；样式表按属性画：侧栏标志与折叠栏标志、侧栏文字标志、新会话页标志、账号行的兜底头像。文字标志的宽高比由浏览器加载图片后从自然尺寸读出，只带 `viewBox` 的 SVG 也能读到。
- 强调色只在配色为 Claude 时生效（D30）：一张样式表用 `color-mix()` 从这一个颜色推出调色板里的各个强调令牌，按钮上的文字取亮暗两种画布色里对比度更高的一个，在 JS 里算好。它的设置行是「配色」的子行（D29）：配色选「跟随宿主」时这一行变灰、不能操作，读者存下的颜色留着。
- 设置页的上传在只读页面不可用：整页控件在禁用的 `fieldset` 里（D60）。

## 理由

- 自定义只换标志与颜色，不带来新的行为分歧，叠一层属性比加第三档品牌改动小：现有按品牌分支的规则都不用决定第三档该落到哪边。
- 图是几 KB 到几百 KB 的二进制，放进设置文档会让每次读写设置都带着它；单独的目录也让读者能直接替换文件。

## 代价

- 宿主半边多三条路由与一个写入目录；只升级插件、没重启宿主时，旧的宿主半边没有这些路由，自定义图缺席。
- 强调色的悬停与链接色是按固定比例混出来的，个别颜色上不如手调的调色板准。

## 重审条件

- 宿主的 `sidebar.brand.mark` / `sidebar.brand.name` 插槽成为稳定扩展点时，侧栏的标志与名称改为注册插槽组件（D43）。
- 宿主提供插件级的文件存储服务时，图改存到那里。
